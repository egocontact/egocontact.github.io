Frequency baseline

Raw phrases retain specificity. Reviewed phrases apply only explicit inflection, plural and wording rules. No embedding threshold merges labels. ID entropy and effective counts describe the existing annotation distribution, not semantic accuracy.

Reviewed relationships

Cosine similarity ranks related language. Opposites, tools versus materials, and objects versus parts can score highly. These decisions preserve those distinctions.
